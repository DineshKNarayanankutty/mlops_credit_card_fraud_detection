# 🧠 ML Crash Course — Project Purpose

This project was created as a quick, practical introduction to machine learning using a real fraud-detection dataset.
Instead of focusing on theory, the goal is to help you understand **how an ML workflow actually works in practice** by walking through it step-by-step with short, focused Python scripts.

Through this crash course, you’ll learn how to:

* Load, inspect, and clean data using **Pandas**
* Prepare features and targets for modeling
* Split data correctly using a **stratified train/test split**
* Train classification models using **scikit-learn**
* Measure model performance using accuracy, precision, recall, and ROC-AUC
* Understand why fraud detection is challenging due to **heavily imbalanced data**
* Compare different models and see how evaluation metrics change

The purpose of this project isn’t to build a production-ready fraud system — it’s to give you a **solid, hands-on foundation** in ML fundamentals so you can confidently move on to more advanced topics later.

To run the scripts, download the dataset from Kaggle:
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

The dataset is purposely not included in this repository to keep the repo lightweight and to follow good version-control practices.
